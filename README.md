## Note

- The app_name app is a sample Django app with the required modules. You can use this app as a sample and create your own apps with any name.
- for core/auth_tools, see imp_bknd_cmpr/Authentication
- for common details (bg_colore, bilingual DB, message translation, pagination, PyICU/persian_sort), see
  imp_bknd_cmpr/CommonPrototype
- for Elasticsearch, see imp_bknd_cmpr/Elasticsearch
- for ipc app, see imp_bknd_cmpr/Inter_Process_Communication (gRPC)
- for core/redis_cache package, see imp_bknd_cmpr/RedisCache
- for swagger/orval example, see imp_bknd_cmpr/Sample_Swagger_Orval
- for system_setting app, see imp_bknd_cmpr/SystemSetting
- Put the items that use web sockets in the project into the app_socket app.
- Place items in the project that require writing tests for the front-end in the app_test_front app.
- Documents, Create a word.docx and ERD.vpp for each microservice according to the examples and place it in this folder.
